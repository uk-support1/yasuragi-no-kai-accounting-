# やすらぎの会 会計アプリ（非公開）

スマホで手軽に入力でき、年1回の会計報告の資料（Excel / 印刷・PDF）をそのまま出力できる会計アプリです。

## データの扱い（重要）
- 会計データは**使う人の端末のブラウザ内だけ**に保存されます。サーバーへは送信しません。
- このリポジトリには**アプリのコードのみ**を置き、実データ（Excel・バックアップ）は絶対にコミットしません（`.gitignore` 済み）。
- 機種変更・ブラウザのデータ消去に備え、「設定 → バックアップを保存」を定期的に実行してください。

## できること
- 入力：支出／収入／口座間移動。科目・口座はワンタップ、摘要は過去の入力から候補表示。ゆうちょ振込は手数料も同時に記録。
- 一覧：月・科目・キーワードで絞り込み、タップで修正・削除。
- 月次：月ごとの収支、口座別の月末残高、毎月の現金チェック（お財布の金額と帳簿の差異）。
- 総会資料（自動作成）：第2号議案 決算報告（予算額・決算額・比較増減・備考、積立口座決算つき）／会計監査報告／第4号議案 来年度予算案／市補助金 実績報告。Excel出力・印刷/PDF・「Word用にコピー」。
- 準備入力：予算額・備考・摘要・監査日などを科目ごとに入力（備考は明細から自動下書き）。
- 内訳・照合：前年度比較、預貯金・現金残高の照合、月別収支、科目別明細、総勘定。
- 取り込み：これまでのExcel（「総勘定」シート）から取り込み。

## 構成
`index.html` / `app.js`（画面） / `core.js`（集計・取り込みロジック） / `papers.js`（総会資料の書類データ） / `vendor/exceljs.min.js`（Excel入出力、MIT） / `sw.js`（オフライン対応）

年度は4月〜翌3月。口座間の資金移動は収支に含めず、残高にのみ反映します。

一般会計の繰越金は、積立口座と「繰越に含めない金額（不明金など）」を除いて計算します。積立口座との資金移動は、決算報告に「積立口座より/へ繰入」として表示します。
